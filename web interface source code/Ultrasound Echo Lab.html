Ultrasound Physics

Ultrasound imaging works exactly like Sonar. It sends a sound pulse into the body and listens for the echo. The time it takes to return tells the machine how deep the organ is.

Distance Equation
d = (v × t) / 2
d = Depth of Organ
v = Speed of Sound in Tissue
t = Total Time of Flight (Round Trip)
(Divided by 2 because the wave travels there AND back)
Piezoelectric Effect
The transducer contains crystals that vibrate when electrified to create sound, and generate electricity when hit by returning sound echoes.
