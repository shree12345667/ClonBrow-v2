Frequency Modulation in Nerves

The human nervous system cannot send "stronger" or "weaker" signals. Action potentials are binary (All-or-Nothing).

Rate Coding To communicate that a touch is "harder", mechanoreceptors fire action potentials faster (higher frequency). A light brush might trigger $10\text{ Hz}$, while a hard press triggers $150\text{ Hz}$.

This bionic interface reads physical Newtons from the piezoresistive sensor and uses a Microcontroller to inject electrical pulses into the nerve at matching frequencies, tricking the brain into "feeling" the object.
