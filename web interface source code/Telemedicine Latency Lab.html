The Human-Machine Bottleneck

In telesurgery, the surgeon's physical movements are encoded, transmitted over a network, and executed by a remote robot.

Latency-Induced Oscillations When latency exceeds 200ms, the visual feedback the surgeon sees is outdated. The surgeon moves to correct an error, but the robot is still executing the *previous* command. This leads to massive overcorrection and dangerous erratic cuts.
