Beer-Lambert Principle

Oxyhemoglobin (HbO₂) Absorbs Infrared light (940nm) more heavily. Allows Red light to transmit, making arterial blood appear bright red.
Deoxyhemoglobin (Hb) Absorbs Red light (660nm) heavily. Allows Infrared light to transmit. High presence indicates hypoxia and causes cyanosis.
