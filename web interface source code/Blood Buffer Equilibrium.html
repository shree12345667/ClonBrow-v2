Blood Buffer System

The body maintains blood pH tightly around 7.4. A buffer system (like Carbonic Acid & Bicarbonate) acts like a chemical seesaw, absorbing excess acids or bases to prevent dangerous pH shifts.

Status: Homeostasis

Blood pH is perfectly balanced at 7.4. The scale is level. Select an action above to disrupt the equilibrium.
